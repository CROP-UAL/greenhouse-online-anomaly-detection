# Experimentos

Los runs nuevos se escriben en `experiments/runs/` y quedan fuera de Git. Cada run debe contener modelos, manifiesto con hashes, versión de código y datos, y parámetros efectivos. Los modelos históricos de referencia también se conservan solo localmente, bajo `approaches/lightgbm/v8_online_2meses/reference_run/`, con su procedencia registrada.
